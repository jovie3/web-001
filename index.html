设置

密钥只留在本机浏览器（localStorage），不会写入代码，也不会上传到本工作台以外的服务器。调用接口时由本地代理临时转发，代理不落盘保存密钥。

模型服务 API 密钥

到 方舟控制台 · API Key 管理 自行创建。新用户通常每个模型有免费 Tokens / 生图额度，用完后请不要在本工具里自行开通付费。同一把钥匙同时用于改写（文本/多模态）和 Seedream 生图。

文本模型 ID

默认使用豆包 Seed 2.1 lite（多模态，可看图改写）。也可填控制台开通的 Model ID 或推理接入点 ep-…。优先消耗免费额度。

生图模型 ID

默认 Seedream 5.0 pro（完整 ID doubao-seedream-5-0-pro-260628，支持 1K / 2K）。若改用 Seedream 5.0 pro / flash，4K 会自动降到 2K。

接口地址（可选）

一般不用改。文档：对话 API、图片生成 API。

小红书 Cookie（可选）

仅保存在本机浏览器 localStorage，不写进代码、不进日志、不上传。未配置时，小红书链接不会发起请求，可改用上传视频/音频文件转写。

抖音 Cookie（可选）

仅保存在本机浏览器 localStorage。未配置时，抖音链接不会发起请求。小红书与 B站不受这一栏影响。

微博 Cookie（可选）

仅保存在本机浏览器 localStorage。未配置时，微博链接不会发起请求。B站走公开接口，不需要任何 Cookie。

保存后立即生效，只写进本机 localStorage。
