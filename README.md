# AI 内容工作台（WEB-001）

小红书笔记改写、AI 生图、发布列表、视频文案提取、商品采集。页面沿用豆包前端壳，本目录补上了全部逻辑与本地接口代理。

## 打开方式（推荐）

在本目录执行：

```bash
python3 server.py
```

浏览器打开终端里提示的地址（默认 http://127.0.0.1:8787/ ）。

这样页面和代理同源，调用火山方舟（豆包文本 / Seedream 生图）时不会被 CORS 拦住。代理只把你在设置里填的密钥临时转发出去，**不写磁盘、不打进日志**。

没有密钥时，切页、校验、模板、发布列表、粘贴/导入商品、导出 Excel 等本地功能仍然可用；改写和生图会明确提示你去设置页填写。

## 也可以直接打开 HTML

把 `index.html` 与 `assets/` 放在同一层，用浏览器打开 `index.html` 也能用全部本地逻辑。若要调用豆包接口，请改用上面的 `python3 server.py` 方式。

## 第一次使用

1. 打开「设置」。
2. 把火山引擎方舟的 **ARK API Key** 填进去（在 [API Key 管理](https://console.volcengine.com/ark/region:ark+cn-beijing/apiKey) 自行创建）。同一把钥匙用于改写和生图。
3. 文本模型默认 `doubao-seed-2-1-lite-260915`，生图默认 `doubao-seedream-5-0-pro-260628`（支持 1K / 2K；选 4K 会自动降为 2K）。可按控制台实际开通的 Model ID 修改，需填完整带版本号的 ID。
4. 点「保存设置」。密钥只存在本机 `localStorage`。
5. 请优先使用控制台里的**免费额度**。额度不够时不要在本工具里自行开通付费，可在设置里改用仍有免费额度的模型。

Cookie 为可选项，只用于尝试解析你自己的链接；按平台分成「小红书 / 抖音 / 微博」三栏，各自只保存在本机浏览器 `localStorage`，不写进代码、不进日志、不上传。B站走公开接口，不需要 Cookie。未配置对应平台 Cookie 时，该平台链接会明确点名提示且**不会发起请求**，请改用「直接粘贴原文」或「上传视频/音频转写」。本工具不收集、不上传 Cookie。

## 链接解析（四平台）

「提取视频文案」可直接粘贴 App 分享文本（正文 + 话题 + 短链 + 杂项码），前端用通用规则抠出全部 `https?://` 词，按域名识别平台；未知域名明确报「暂不支持该链接」。服务端 `/api/resolve-link` 用 **GET** 跟随跳转（上限 10 跳、浏览器 UA、超时 20 秒；**不用 HEAD**，抖音与小红书短链对 HEAD 返回 404），得到最终地址；命中登录墙/访客墙时，从 `redirectPath`（小红书）或 `url`（微博）参数 URL 解码出真实地址，返回 `{platform, contentId, finalUrl, realUrl}`。

| 平台 | 短链域名 | 内容页域名 | 取文案方式 | Cookie |
|---|---|---|---|---|
| 抖音 | `v.douyin.com` | `douyin.com`、`iesdouyin.com` | 先取 `/video/<id>` 页面，取不到改调 `iesdouyin.com/web/api/v2/aweme/iteminfo/?item_ids=<id>`；两路都不通明确报错，不编文案 | 需要抖音 Cookie |
| 小红书 | `xhslink.com`、`xhslink.cn` | `xiaohongshu.com`、`xiaohongshu.cn` | `discovery/item/<id>`，沿用 `og:* / window.__INITIAL_STATE__` 提取 | 需要小红书 Cookie |
| B站 | `b23.tv` | `bilibili.com`、`m.bilibili.com` | 优先公开接口 `api.bilibili.com/x/web-interface/view?bvid=<BV>` 取标题与简介，接口不通再解析页面 | **不需要** |
| 微博 | `t.cn` | `weibo.com`、`weibo.cn`、`m.weibo.cn` | 取微博内容页 | 需要微博 Cookie |

「小红书 AI 改写」**只支持小红书链接**；粘贴其他平台链接时明确提示「改写目前只支持小红书链接」，不会当小红书处理。

## 五个功能

- **小红书 AI 改写**：链接 / 图片 / 商品笔记。无链接会红字拒绝；可展开「直接把原文贴进来」。最多 10 个改写窗口。结果可编辑、复制、保存到发布列表。
- **AI 生图**：描述、张数 1/2/4、比例、分辨率、参考图、优化提示词、8 个风格模板 + 新建。空描述时按钮禁用。生成后进入会话页（查看大图、重新生成同款、取消基准、下载、选择图片）。本地模式，无积分消耗。
- **发布列表**：本地保存。筛选、搜索、批量、排序、空状态。顶部「新建」回到改写页。
- **提取视频文案**：支持抖音 / 小红书 / B站 / 微博分享文本与短链，每行可含多条链接，异步提取，记录在左侧。按平台门控 Cookie（B站免 Cookie）；未配对应平台 Cookie 时明确提示平台名且不发请求，可改走上传转写。分段结果可复制全文或某段。
- **商品采集**：因没有可用的免费搜索接口，请粘贴商品链接或导入 CSV / Excel，整理后导出。记录保留 30 天，超时自动清理。失败行会如实显示原因。
